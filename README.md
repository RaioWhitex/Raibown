# 🌑 Hover Button UI

Uma interface minimalista desenvolvida com foco em interatividade, elegância e experiência do usuário, apresentando um botão centralizado com efeito visual de destaque ao passar o cursor do mouse.

---

## 📸 Preview do Projeto

Interface contendo:

- Fundo escuro moderno
- Botão centralizado
- Texto interativo "Hover Me"
- Bordas arredondadas
- Efeito hover animado
- Design clean e minimalista
- Destaque visual ao interagir

---

## ✨ Tecnologias Utilizadas

- **HTML5**
- **CSS3**

---

## 🎨 Características do Design

- Interface minimalista
- Tema dark moderno
- Botão com cantos arredondados
- Centralização completa utilizando Flexbox
- Efeitos de transição suaves
- Destaque visual durante a interação
- Contraste elevado para melhor legibilidade
- Aparência profissional e elegante

---

## 🚀 Objetivo do Projeto

Praticar conceitos de desenvolvimento front-end relacionados à criação de botões interativos, animações CSS, efeitos hover e técnicas modernas de alinhamento e estilização de componentes visuais.

---

## 📚 Funcionalidades

- Botão responsivo
- Efeito hover animado
- Feedback visual para interação do usuário
- Centralização horizontal e vertical
- Transições suaves com CSS
- Estrutura simples e reutilizável
